# Anti-Slop Design & Quality Gate Guide (KHM Quality Guard)

This guide provides developers and teammates with operational instructions on utilizing the three core frontend design skills and automated HTML/CSS quality gates integrated into the repository to eliminate generic "AI Slop" and enforce high-craftsmanship industrial standards across the Kha Hoàng Minh web portal.

---

## 1. Overview of Core Skills

The Google Antigravity agent environment for this project is provisioned with three specialized skills located in `.agents/skills/` (project-level) and `~/.antigravity/skills/` (global user environment):

| Skill Name | Upstream Source | Primary Function in KHM |
|---|---|---|
| **`anti-slop-design`** | `wwewtech/anti-slop-design` | Enforces the **12 Banned AI Slop Tropes** and mandates the **7-Axis Pre-Emit Quality Gate** ($\ge 4/5$). |
| **`taste-skill`** | `Leonxlnx/taste-skill` | Provides art direction standards, layout proportions, and multi-viewport real-browser visual auditing. |
| **`anti-slop`** | `@gessobuild/anti-slop` | Runs **73 deterministic HTML/CSS design lint guards** (detects layout collapses, text-gradient tells, puffy shadows, spacing bugs). |

> [!IMPORTANT]
> **Kha Hoàng Minh Industrial Palette Lock**:
> All components and pages must strictly adhere to the industrial metallurgy design system defined in [`.agents/rules/ui.md`](../.agents/rules/ui.md):
> - **Brushed Charcoal Gunmetal Surfaces**: `#0B0F17` (Canvas Tier 0), `#111827` (Band Tier 1), `#182234` (Card Tier 2 with specular highlight `inset 0 1px 0 rgba(255,255,255,0.08)`).
> - **Molten Industrial Accents**: Molten Weld-Orange (`#EA580C` / `#FB923C`) and Shop-Floor Amber (`#F59E0B`).
> - **Strictly Prohibited**: Generic SaaS palettes (`indigo-*`, `purple-*`, `violet-*`) or blurry background radial gradient blobs.

## 2. Automated HTML/CSS Verification (73 Design Guards)

### Method 1: Using the Built-In npm Script (Recommended)
After generating a static production build (`client/out/`):

```bash
cd client
npm run build
npm run check:anti-slop
```

This scans all 15 static HTML pages generated by Next.js and provides detailed warnings for any layout collapses, typographic anomalies, or visual tells.

### Method 2: Running Directly on Any File or Directory
Run the CLI tool directly via `npx` from any directory:

```bash
# Audit the entire static output directory with marketing copy mode (em-dashes reported as advisory)
npx -y @gessobuild/anti-slop check out --marketing

# Audit a specific HTML file
npx -y @gessobuild/anti-slop check client/out/index.html

# Output JSON report for CI/CD integration
npx -y @gessobuild/anti-slop check client/out --json
```

### Method 3: Deterministic Auto-Fixer
The tool provides idempotent auto-fixers for simple tells and layout bugs:

```bash
# Preview proposed fixes on stdout
npx -y @gessobuild/anti-slop fix client/out/index.html

# Apply fixes directly in-place
npx -y @gessobuild/anti-slop fix client/out/index.html --write
```

## 3. The 7-Axis Pre-Emit Quality Gate Checklist

Before delivering code or marking a UI task complete, developers and AI agents must evaluate the implementation against the 7-Axis Quality Gate. **Every axis must achieve a score of $\ge 4/5$:**

```
┌────────────────────────────────────────────────────────────────────────┐
│                   THE 7-AXIS PRE-EMIT QUALITY GATE                     │
├──────────────────────────┬─────────────────────────────────────────────┤
│ 1. Anti-Slop Purity      │ Zero purple/indigo blobs, emojis, or slop   │
│ 2. UX Speed & 1-to-3     │ 1 focal action, max 3 secondary actions     │
│ 3. Typographic Balance   │ <= 2 font families; tabular numbers; <= 75ch│
│ 4. Spacing Geometry      │ 4px/8pt strict grid; R_inner = R_outer - P  │
│ 5. Micro-Interactions    │ Fast snappy motion (< 200ms); active scale  │
│ 6. Accessibility & Flow  │ Visible focus rings; WCAG AA; aria labels   │
│ 7. Multi-Viewport Budget │ Zero horizontal overflow (360px to 1920px+) │
└──────────────────────────┴─────────────────────────────────────────────┘
```

1. **Anti-Slop Purity**:
   - [ ] Zero purple/indigo radial background blobs
   - [ ] Zero raw emojis used as functional icons
   - [ ] Zero single-word italicized/gradient headings
   - [ ] Zero fabricated vanity metrics (`"+99.9% Uptime"`, `"10x Faster"`)
2. **UX Speed & The 1-to-3 Rule**:
   - [ ] Exactly 1 unambiguous primary CTA per viewport section
   - [ ] Maximum 3 supporting secondary actions/links
   - [ ] Page-level centralized control bars (no duplicate date pickers per card)
   - [ ] Direct sales hotlines (`0979.866.162` - Ms. Phụng Uyên, `0976.888.999` - Ms. Minh Hải) and Zalo access
3. **Typographic Discipline**:
   - [ ] Maximum 2 font families across the entire view
   - [ ] Tabular numerals enabled on all tabular/metric figures (`tabular-nums`)
   - [ ] Body copy line length bounded to $\le 75\text{ch}$ for effortless reading
   - [ ] Sentence case on labels; zero all-caps tracking screaming
4. **Spacing & Micro-Geometry**:
   - [ ] Strict 4px/8pt spatial rhythm (`4px`, `8px`, `12px`, `16px`, `24px`, `32px`)
   - [ ] Nested corner radius formula respected: $R_{\text{inner}} = \max(0, R_{\text{outer}} - P)$
   - [ ] Minimum 16px internal card padding
   - [ ] Optical alignment on icon-text button pairings
5. **Micro-Interactions & Motion**:
   - [ ] Transitions snappy and under 200ms
   - [ ] Tactile micro-scaling on click (`:active { transform: scale(0.97) }`)
   - [ ] Full support for `prefers-reduced-motion: reduce` (pauses marquees and pulses)
6. **Accessibility & Keyboard Navigation**:
   - [ ] Visible focus rings on all interactive elements (`:focus-visible`)
   - [ ] Semantic HTML tags (`<button>`, `<a>`, `<nav>`, `<main>`, `<header>`)
   - [ ] Icon-only buttons contain descriptive `aria-label` attributes
   - [ ] WCAG 2.2 AA / AAA color contrast on body text (`dark:text-slate-200`)
7. **Mobile & Multi-Viewport Linearity**:
   - [ ] Clean vertical stacking on small viewports
   - [ ] Zero horizontal scroll overflow across `360px`, `640px`, `768px`, `1024px`, and `1440px`
   - [ ] Interactive touch targets $\ge 44 \times 44\text{px}$ on touchscreens
   - [ ] Full-width button stacking on mobile (`w-full sm:w-auto`)

## 4. The 12 Banned AI Slop Tropes & Mandatory Replacements

| # | Banned AI Slop Trope | Typical Manifestation in Vibe-Coded UI | Mandatory KHM Production Replacement |
|---|---|---|---|
| 1 | **AI Dark Mode Blob** | `radial-gradient` purple/indigo blurred in dark background corners. | Deep Gunmetal `#0B0F17` surfaces with subtle 1px hairline borders (`rgba(255,255,255,0.08)`). |
| 2 | **Monotonous Slate/Indigo** | Generic `bg-slate-900 text-slate-400 bg-indigo-600` boilerplate. | Brushed metallic charcoal (`#0B0F17`, `#111827`, `#182234`) anchored by molten weld-orange (`#EA580C`). |
| 3 | **Cookie-Cutter 3-Card Grid** | Three identical rectangular cards with generic glowing hover borders. | Dynamic 12-column asymmetric splits (`7/5` or `8/4`) or content-driven bento layouts. |
| 4 | **Raw Emojis as Icons** | Using emojis (`🚀`, `🔥`, `💡`, `📊`) inside buttons and cards. | Crisp vector SVGs (Lucide React, Radix UI) with unified 1.5px/2px stroke widths. |
| 5 | **Fabricated Vanity Stats** | Filler metrics (`"+99.9% Uptime"`, `"10x Faster"`, `"50k+ Users"`). | Authentic corporate telemetry: Tax ID `0314059766`, certified SUS grades, and real warehouse locations. |
| 6 | **Screaming Eyebrow Labels** | Tracked-out uppercase labels above every heading (`OVERVIEW`, `FEATURES`). | Sentence-case hierarchy, subtle metadata tags, or omit entirely if redundant. |
| 7 | **Single-Word Italic/Color Accents** | Headlines with one arbitrary word italicized or highlighted in gradient text. | Uniform, confident typographic weight representing industrial metallurgy authority. |
| 8 | **Redundant Metric Duplication** | Repeating metrics in header, sidebar, and inside multiple cards. | Single Source of Metric Truth: one primary KPI summary per viewport. |
| 9 | **Card-Level Filter Pollution** | Embedding separate date pickers or filters inside every card. | Unified **Page-Level Control Bar** synchronizing all active views. |
| 10 | **Vanity Visual Space-Wasters** | Giant decorative 3D globes or blurred shapes consuming 60% of screen. | Compact specification tables, dimension comparisons, and CNC capability lists. |
| 11 | **Missing Interactive States** | Buttons with only hover effects; missing focus, active, loading, and disabled states. | **8-State Interactive Feedback System** including `Loader2 animate-spin` and disabled states. |
| 12 | **Broken Placeholders & Links** | `via.placeholder.com`, broken stock photos, or dead `#` anchor tags. | Verified local assets, studio-lit platinum stages for partner logos, and active routes. |
